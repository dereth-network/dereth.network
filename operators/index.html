Bring your world to the Dereth Network

Register (or claim) your world, prove you run it, and put its key in your server. Each character joins on its own, with @dn on.

  1. Sign in with Discord. The hub keeps your Discord id and name, and when you signed in; nothing else.
  2. Register your world, or claim its listing if it's already in the world list.
  3. Save its key, which is shown once, and give it to your server.
    • Running ACE? Set up the Dereth.Network mod.
    • Running Empyrean? Dereth Network support is built in under the [federation] setting.
    • Running GDLE? GDLE is closed source, without mods. We'd love to build support.
  4. Prove you run it, with a token on a page on the world's own host, or with @dn verify typed by an Admin in game.
  5. Once it's proven, the network turns on for the world by itself.

Operator commands
@dn verify <token>
Admins only. Proves to the hub that the world is yours.
@dn admin block leafcull
Sentinels and up can block a world or a single character (An Adventurer@leafcull).
@dn admin unblock leafcull
Lift a block on a world or character.
@dn admin block
With nothing after it, as @dn admin unblock too: show this world's blocks and its link to the network.
@dn admin global
Show which room carries cross-world Global chat now.
@dn admin global trade
Sentinels and up can move cross-world Global chat to another of the world's rooms (general, trade, lfg, roleplay, or off for none).

Operators sign in with Discord. The hub asks Discord only who you are, and keeps no Discord token.

Your worlds

Register a world

A new world is listed nowhere until you prove you run it. Its key comes with it, shown once.

Claim a listing

Worlds carried over from the community's server list belong to nobody yet. If one of them is yours, claim it: the listing stays as it is until you prove you run the world, then it's yours to manage.
